# Code Mentor Backend

Code Mentor Backend es una skill de tutoría para aprender a leer, escribir, refactorizar y depurar código C# y .NET backend. Guía al estudiante paso a paso, con explicaciones breves, ejemplos y preguntas de comprensión.

## Cómo ayuda

- Explica conceptos y vocabulario técnico y corrige errores de forma respetuosa.
- Ayuda a seguir llamadas y responsabilidades dentro de proyectos reales.
- Guía la depuración y las pruebas de regresión a partir de evidencias.
- Propone ejercicios, repasos y notas de aprendizaje; el registro requiere almacenamiento accesible y configurado.
- Adapta el estudio de documentación a conocimientos demostrados y prerrequisitos.
- Propone fichas personales con ID, fechas e historial; pide aceptación antes de guardarlas.
- Cierra sesiones con avances, dificultades, ayudas docentes y próximo paso. Sin escritura, prepara un único lote pendiente para aplicar con Work cuando el usuario lo active.
- Puede adaptar una clase para una conversación oral cuando la plataforma y el dispositivo permiten usar voz.

## Uso

La skill está en `skills/code-mentor-backend/`. En una superficie compatible, puedes pedir: «Usa Code Mentor Backend para ayudarme a entender este código, un concepto cada vez».

La disponibilidad de skills, voz y acceso a archivos depende de la plataforma. La memoria no se sincroniza automáticamente entre dispositivos ni funciona en segundo plano. El profesor puede cometer errores: revisa los cambios y comprueba el código antes de aplicarlo.

## Biblioteca de conocimientos y estructura

Consulta la [guía de estudio y fichas personales](docs/knowledge-library.md) para conocer cuándo se proponen actualizaciones, cómo se conserva el avance y qué ocurre sin acceso al almacenamiento.

La skill combina SKILL.md, referencias docentes, plantillas y utilidades de registro local. Tus fichas y registros reales se mantienen fuera del paquete y de este repositorio público. Las plantillas no son un historial de aprendizaje ya creado.

La [guía de cierre y memoria](docs/session-memory.md) explica qué se registra, cuándo se propone Work y cómo comprobar que un guardado ocurrió. Activar la skill no crea carpetas ni permisos por sí solo.

## Adaptación de la enseñanza

El profesor combina preferencias y resultados observados para elegir ayudas según el concepto y el contexto. La [guía de adaptación](docs/adaptive-teaching.md) explica el registro privado y sus gráficos, sin estilos fijos ni promesas de eficacia.
