# Code Mentor Backend

Profesor personal para aprender C# y .NET backend mediante explicaciones progresivas, lectura de código, práctica y depuración guiada.

La skill se encuentra en `skills/code-mentor-backend/`. Incluye instrucciones, referencias y una utilidad opcional para registrar aprendizaje en archivos locales cuando el entorno lo permite.

El proyecto está en preparación. La disponibilidad en distintas superficies, la sincronización de registros y la experiencia por voz dependen del entorno utilizado. No incluyas código confidencial, credenciales ni datos de terceros en ejemplos compartidos.

Autor: David Valadés.
