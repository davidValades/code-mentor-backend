# Política de privacidad de Code Mentor Backend

Responsable y contacto: David Valadés — davidvaladesnavarro@gmail.com.

## Uso de la skill

Code Mentor Backend proporciona instrucciones para aprender C# y .NET. Su creador no recopila automáticamente conversaciones, código ni registros de aprendizaje, ni ha añadido servicios propios de análisis o recogida de datos.

Si el entorno lo permite y el usuario lo configura, el asistente puede guardar archivos de aprendizaje en una ubicación accesible para él. Su contenido, ubicación, acceso y conservación dependen de la plataforma y de la configuración del usuario. La skill no sincroniza automáticamente los registros entre dispositivos.

La biblioteca opcional de conocimientos utiliza fichas Markdown, un índice e historial de revisiones en una ubicación acordada. El asistente propone los cambios y solicita aceptación antes de guardarlos. Esos archivos no se publican automáticamente en este repositorio ni se envían al creador.\n\nNo compartas credenciales ni información de tu empresa que no estés autorizado a utilizar o guardar.

El registro opcional de adaptación vincula ayudas docentes con evidencias ya guardadas y genera balances y gráficos locales. Las preferencias declaradas y estos derivados permanecen en la ubicación y ámbito autorizados, sin enviarse automáticamente al creador. Las solicitudes de eliminación deben contemplar también estos archivos y sus copias accesibles.

## Soporte

Puedes solicitar ayuda mediante las incidencias de este repositorio. Las incidencias públicas y su contenido pueden ser visibles para cualquier persona. No incluyas contraseñas, claves, datos personales, conversaciones privadas ni código confidencial. El creador puede leer y responder lo publicado. GitHub gestiona sus propios servicios y conserva o elimina información conforme a sus políticas y controles.

## Consultas privadas

Para consultas sobre los datos que hayas facilitado al creador, escribe a davidvaladesnavarro@gmail.com. Las consultas se conservan hasta su resolución y durante un máximo de 90 días después; el responsable debe revisar y eliminar los mensajes manualmente.

Puedes solicitar información, corrección o eliminación de los datos que hayas facilitado, sujeto a los límites y obligaciones aplicables. El creador no controla los datos que conservan las plataformas ni puede garantizar su eliminación de los sistemas de terceros.

## Plataformas

ChatGPT, Codex, GitHub y el proveedor de correo pueden tratar información conforme a sus propias políticas. Consulta sus respectivas condiciones y políticas de privacidad.
