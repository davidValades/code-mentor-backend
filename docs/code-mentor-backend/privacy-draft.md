## Using the skill

Code Mentor Backend offers instructions to guide learning C# and .NET. The creator does not intend to collect additional data from skill users or automatically receive their learning records.

When the environment supports it and the user configures it, the skill can save learning files in a location accessible to the assistant. The content and location depend on the environment and the agreement with the user. The skill does not itself guarantee synchronization of these records between devices. The user must follow applicable rules for company information and avoid saving credentials or data they should not retain.

## Support issues

If the user opens a GitHub issue, the data they include will be processed through GitHub and may be public when the repository is public. Do not include passwords, keys, personal data, private conversations, or confidential code. The creator can read and respond to information posted in the issue.

## Platforms used

Conversations, files, and use of the skill may be subject to the terms and policies of the platform the user chooses, such as ChatGPT, Codex, or GitHub. This draft does not replace those platforms' privacy information or claim that they process data identically.
