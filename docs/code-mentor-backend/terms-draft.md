## Purpose

Code Mentor Backend is a skill intended to guide learning C# and .NET backend development through explanations, exercises, and help reading, refactoring, and debugging code. The creator intended to offer it free of charge, with no in-skill purchases.

## Use and availability

The experience depends on the features and permissions available on the chosen platform. Some options, such as voice or access to persistent files, may not be available on every device. The skill does not guarantee synchronization between environments or execute tasks by itself without an active session.

## Results and content

Generated responses may contain errors or be incomplete. The user should review proposals and check them in their project before applying them. The user is responsible for sharing only code and data they are authorized to use on the chosen platform; they should avoid including secrets or confidential data without authorization.

## Memory and privacy

When the environment and the user allow it, the skill can maintain learning records in files. Their location, access, and retention depend on the agreed configuration. See this repository's [historical privacy draft](privacy-draft.md) for the planned data and contact information at that time.
