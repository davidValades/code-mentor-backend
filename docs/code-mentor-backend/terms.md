# Code Mentor Backend terms of use

Code Mentor Backend, by David Valadés, is a free tutoring skill for learning C# and .NET backend development, with no in-skill purchases.

The experience depends on the features and permissions available in the environment. Voice and persistent storage may not be available on every device. The skill does not guarantee synchronization between environments or run tasks autonomously without an active session.

Knowledge cards are learning summaries saved after you accept their proposed content and when accessible storage is available. Reading documentation or a card does not, by itself, demonstrate mastery of a topic.

Strategy summaries describe observations and their limitations. They do not diagnose learning styles, demonstrate causality, or guarantee educational results.

Responses may be incorrect or incomplete. Review proposals and check the code before applying it. Share only code and data whose use on the platform is authorized; avoid publishing secrets or confidential information.
