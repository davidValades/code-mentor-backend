# Información de privacidad — borrador

**Borrador pendiente de revisión y publicación.** Este documento describe el funcionamiento previsto de Code Mentor Backend y necesita completarse con la información de contacto, conservación y gestión de solicitudes antes de utilizarse como política definitiva.

## Uso de la skill

Code Mentor Backend ofrece instrucciones para orientar el aprendizaje de C# y .NET. El creador no pretende recopilar datos adicionales de quienes usan la skill ni recibe automáticamente sus registros de aprendizaje.

Cuando el entorno lo permite y el usuario lo configura, la skill puede guardar archivos de aprendizaje en una ubicación accesible para el asistente. El contenido y la ubicación dependen del entorno y de lo acordado con el usuario. La skill no garantiza por sí sola que esos registros se sincronicen entre dispositivos. El usuario debe respetar las normas aplicables a información de su empresa y evitar guardar credenciales o datos que no deba conservar.

## Incidencias de soporte

Si el usuario abre una incidencia en GitHub, los datos que incluya serán tratados a través de GitHub y podrán ser públicos cuando el repositorio sea público. Se recomienda no incluir contraseñas, claves, datos personales, conversaciones privadas ni código confidencial. El creador podrá leer y responder a la información publicada en la incidencia.

## Plataformas utilizadas

Las conversaciones, los archivos y el uso de la skill pueden estar sujetos a las condiciones y políticas de la plataforma que el usuario utilice, como ChatGPT, Codex o GitHub. El presente borrador no sustituye la información de privacidad de esas plataformas ni afirma que sus tratamientos sean idénticos.

## Contacto para privacidad

Para consultas privadas relacionadas con los datos de los usuarios, la dirección prevista es **codementorbackend.privacy@gmail.com**. Antes de publicar esta política, queda pendiente comprobar que el buzón recibe mensajes y concretar cómo se gestionarán las solicitudes.
