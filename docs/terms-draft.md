# Condiciones de uso — borrador

Este documento es un borrador para revisión. Todavía no son condiciones publicadas ni una descripción de todas las obligaciones legales aplicables.

## Finalidad

Code Mentor Backend es una skill destinada a orientar el aprendizaje de C# y .NET backend mediante explicaciones, ejercicios y ayuda para leer, refactorizar y depurar código. El creador ha previsto ofrecerla gratuitamente, sin compras dentro de la skill.

## Uso y disponibilidad

La experiencia depende de las funciones y permisos disponibles en la plataforma utilizada. Algunas opciones, como la voz o el acceso a archivos persistentes, pueden no estar disponibles en todos los dispositivos. La skill no garantiza sincronización entre entornos ni ejecuta tareas por sí sola cuando no hay una sesión activa.

## Resultados y contenido

Las respuestas generadas pueden contener errores o quedar incompletas. El usuario debe revisar las propuestas y comprobarlas en su proyecto antes de aplicarlas. El usuario es responsable de compartir únicamente código y datos que esté autorizado a utilizar en la plataforma elegida; debe evitar incluir secretos y datos confidenciales sin autorización.

## Memoria y privacidad

Cuando el entorno y el usuario lo permiten, la skill puede mantener registros de aprendizaje en archivos. Su ubicación, acceso y conservación dependen de la configuración acordada. Consulta el borrador de privacidad de este repositorio para conocer la información prevista sobre datos y contacto.

## Archivos y licencia
