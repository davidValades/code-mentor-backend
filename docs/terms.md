# Condiciones de uso de Code Mentor Backend

Code Mentor Backend, de David Valadés, es una skill gratuita de tutoría para aprender C# y .NET backend, sin compras dentro de la skill.

La experiencia depende de las funciones y permisos disponibles en el entorno. La voz y el almacenamiento persistente pueden no estar disponibles en todos los dispositivos. La skill no garantiza sincronización entre entornos ni ejecuta tareas autónomamente sin una sesión activa.

Las fichas de conocimiento son resúmenes de aprendizaje que se guardan tras aceptar su propuesta y cuando existe almacenamiento accesible. Leer documentación o una ficha no acredita por sí solo dominio del tema.\n\nLos balances de estrategias describen observaciones y sus límites. No diagnostican estilos de aprendizaje, demuestran causalidad ni garantizan resultados educativos.

Las respuestas pueden ser incorrectas o incompletas. Revisa las propuestas y comprueba el código antes de aplicarlo. Comparte únicamente código y datos cuyo uso en la plataforma esté autorizado; evita publicar secretos o información confidencial.

Los archivos de este repositorio se distribuyen bajo la licencia MIT incluida en LICENSE. Las plataformas utilizadas pueden tener condiciones propias.

El soporte se ofrece mediante las incidencias de GitHub, sin plazo de respuesta garantizado. Las consultas privadas sobre datos pueden dirigirse a davidvaladesnavarro@gmail.com. Consulta la [política de privacidad](privacy.md).
