# Skill title

## Goal

State the user outcome and scope in one sentence.

## Context

Use compact technical instructions and factual coordination notes. Read only relevant references and current records. Keep conditions, uncertainty, permissions and identifiers exact. This rule does not change the user-facing response format or language below.

## Workflow

1. Establish the objective and necessary inputs.
2. Select only the reference needed for the current step.
3. Perform authorized work; verify the result.
4. Report actual outcome, limits and next action.

## Output

Define the response format, level of explanation and language behavior for this skill. Keep teaching, accessibility and required detail independent from internal brevity.

## Boundaries

Define domain-specific permissions, data handling, uncertainty and failure behavior. Keep real personal data outside the skill and public repository.
